# own-ui

Showcase y catálogo de componentes de interfaz propios construidos sobre las primitivas headless de **Base UI**.

## Propósito

- **Componentes propios:** Primitivas reutilizables y neutras en maquetación, despojadas de estilos rígidos.
- **Guidelines de diseño:** Reglas y convenciones visuales comunes (elevación de superficies, tríadas funcionales, tipografía y tokens).
- **Herramientas de soporte:** Utilidades de diseño integradas, incluyendo generadores de paletas cromáticas para proyectos.
