# own-ui

Showcase y catálogo de componentes de interfaz reutilizables. Las familias de `base/` se construyen sobre las primitivas de **Base UI**.

## Propósito

- **Componentes propios:** Primitivas reutilizables y neutras en maquetación, despojadas de estilos rígidos.
- **Guidelines de diseño:** Reglas y convenciones visuales comunes (elevación de superficies, tríadas funcionales, tipografía y tokens).
- **Herramientas de soporte previstas.** El generador de paletas cromáticas es la primera utilidad proyectada. [Objetivos del proyecto](docs/master/03-objetivos.md)
